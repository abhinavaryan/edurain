Class 10 Maths Chapter 5 Arithmetic Progression Guide

Arithmetic progressions are part of the Algebra unit in CBSE Class 10 Mathematics. This guide to Class 10 Maths Chapter 5 Arithmetic Progression covers the definition, key terms, the nth term, sum formulas, solved examples, and common mistakes. It follows the NCERT textbook and is meant for 10th board exam preparation.

What Is an Arithmetic Progression and Which Terms Matter

An arithmetic progression, or AP, is a list of numbers in which each term after the first is found by adding a fixed number to the previous term. This fixed number is called the common difference.

Remember these three types of AP:

APFirst term (a)Common difference (d)Type
2, 4, 6, 8, ...22Increasing
10, 7, 4, 1, ...10−3Decreasing
5, 5, 5, 5, ...50Constant

The sequence 1, 4, 9, 16 is not an AP. The gaps are 3, 5, and 7, so the difference is not fixed.

Students should know the standard notation used in Arithmetic Progression Class 10 questions:

SymbolMeaning
aFirst term
dCommon difference, found as the second term minus the first term
nNumber of terms
aₙThe nth term, also called the general term
lLast term of a finite AP
SₙSum of the first n terms


Three numbers a, b, and c are in AP when 2b = a + c. This test appears often in board questions.

How to Find the nth Term of an AP

The nth term of an AP is aₙ = a + (n − 1)d. Here a is the first term and d is the common difference. This formula gives any term directly without writing all the earlier terms.

If the last term l is known, the nth term from the end is l − (n − 1)d. Use this when a question counts terms from the last number.

Follow these steps to find the nth term of AP questions quickly:

  1. Write down the first term a.
  2. Find d by subtracting any term from the next term.
  3. Substitute a, d, and n in aₙ = a + (n − 1)d.
  4. Simplify carefully, keeping track of negative signs.

Sum of the First n Terms and Arithmetic Progression Formulas

The sum of the first n terms of an AP is Sₙ = n/2 [2a + (n − 1)d]. When the last term l is known, use Sₙ = n/2 (a + l). Both give the same result.

Here are the main Arithmetic Progression formulas in one place:

Use the second sum formula when the last term is given. Use the first when only a, d, and n are known.

Solved Examples with Clear Steps

Solving examples in a fixed order reduces errors. First list a, d, and n. Then pick the right formula. Finally substitute, simplify and state the answer with units where needed.

Example 1: Find the 10th term of the AP 2, 7, 12, ...

Here a = 2 and d = 5. So a₁₀ = 2 + (10 − 1) × 5 = 2 + 45 = 47.

Example 2: Which term of the AP 3, 8, 13, 18, ... is 78?

Here a = 3 and d = 5. Set aₙ = 78. Then 3 + (n − 1) × 5 = 78, so (n − 1) × 5 = 75 and n − 1 = 15. Hence n = 16. The 16th term is 78.

Example 3: Find the sum of the first 20 terms of 5, 8, 11, ...

Here a = 5, d = 3 and n = 20. S₂₀ = 20/2 × [2 × 5 + 19 × 3] = 10 × [10 + 57] = 10 × 67 = 670.

Example 4: Find the sum of the first 15 multiples of 8.

The AP is 8, 16, 24, ..., 120. Here a = 8, l = 120 and n = 15. S₁₅ = 15/2 × (8 + 120) = 15/2 × 128 = 15 × 64 = 960.

Example 5: The 4th term of an AP is 9 and the 8th term is 17. Find the 20th term.

Using the nth term formula, a + 3d = 9 and a + 7d = 17. Subtracting gives 4d = 8, so d = 2. Then a = 9 − 6 = 3. Therefore a₂₀ = 3 + 19 × 2 = 41.

Common Mistakes and How to Avoid Them

Most lost marks come from sign errors and formula slips. Writing the values of a, d and n before substituting prevents many of these mistakes in the exam hall.

  1. Using n instead of n − 1. The nth term formula contains (n − 1)d, not nd.
  2. Finding d in the wrong direction. Always subtract the earlier term from the later term.
  3. Ignoring negative signs. In a decreasing AP, d is negative, so put it in brackets while substituting.
  4. Calling any pattern an AP. Check that the difference is the same for every pair of consecutive terms.
  5. Mixing the two sum formulas. Use n/2 (a + l) only when the last term is given.
  6. Accepting a negative or fractional n. The number of terms must be a positive whole number.

Key Takeaways

  1. An AP has a fixed common difference between consecutive terms.
  2. The nth term is aₙ = a + (n − 1)d.
  3. The sum of n terms is Sₙ = n/2 [2a + (n − 1)d], or n/2 (a + l) when the last term is known.
  4. Three numbers a, b and c are in AP when 2b = a + c.
  5. Listing a, d, and n before substituting helps avoid sign and formula errors.

Frequently Asked Questions (FAQs)

FAQ 1: What is the formula for the nth term of an AP?

The nth term is aₙ = a + (n − 1)d. Here a is the first term, d is the common difference, and n is the position of the term.

FAQ 2: How do you find the common difference of an AP?

Subtract any term from the term that follows it. For the AP 4, 9, 14, the common difference is 9 − 4 = 5. The value must be the same for every pair.

FAQ 3: Which sum formula should I use for an AP?

Use Sₙ = n/2 [2a + (n − 1)d] when the first term and common difference are known. Use Sₙ = n/2 (a + l) when the last term is given.

FAQ 4: How can I check whether a list of numbers is an AP?

Find the differences between consecutive terms. If all differences are equal, the list is an AP. For three numbers a, b, and c, you can also check whether 2b = a + c.

FAQ 5: Can the common difference of an AP be negative or zero?

Yes. A negative d gives a decreasing AP such as 10, 7, 4. A zero d gives a constant AP such as 5, 5, 5, where every term is the same.

FAQ 6: How should students prepare this chapter for the board exam?

Learn the formulas, solve all NCERT exercises, and practise previous year questions in timed sessions. Keep a short error notebook and revise it before the exam.
