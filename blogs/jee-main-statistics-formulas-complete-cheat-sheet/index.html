JEE Main Statistics Formulas: Complete One-Page Cheat Sheet | EduRain Blog

JEE Main Statistics Formulas cover mean, median, mode, mean deviation, variance, standard deviation, and coefficient of variation. Students need the ungrouped and grouped forms, the shortcut methods, and the effect of shifting and scaling on each measure. This cheat sheet lists the core formulas with usage notes, solved examples, and common mistakes.

Which statistics topics appear in the JEE Main syllabus?

The JEE Main Mathematics syllabus includes measures of central tendency and dispersion for grouped and ungrouped data. These are mean, median, mode, mean deviation, variance, and standard deviation. Always confirm the current topic list in the official NTA syllabus for 2027.

Statistics usually sits beside probability in the same unit, so the topic is compact and formula-driven. The NCERT Class 11 Statistics chapter is the best base for concepts. JEE questions then add shortcut methods, combined data sets, and changes in the data values.

Weightage changes every year, so this guide does not quote any fixed number of questions.

What are the essential formulas for statistics in JEE Main?

Statistics formulas fall into three groups: central tendency, dispersion, and transformation rules. Learn each group with its grouped data version, because JEE Main often tests frequency tables and combined data sets.

Which formulas give mean, median, and mode?

The mean divides the sum of observations by their count. Grouped data uses frequency-weighted sums. The median uses cumulative frequency, and the mode uses the modal class frequencies.

MeasureUngrouped dataGrouped data
Meanx̄ = Σx / nx̄ = Σfx / Σf
Assumed mean methodx̄ = A + Σd / nx̄ = A + Σfd / Σf, where d = x − A
Step deviation methodNot neededx̄ = A + h × Σfu / Σf, where u = (x − A) / h
MedianMiddle value after sortingl + [(N/2 − C) / f] × h
ModeMost frequent valuel + [(f1 − f0) / (2f1 − f0 − f2)] × h


Here l is the lower limit of the median or modal class, C is the cumulative frequency before the median class, f is the frequency of that class, and h is the class width. In the mode formula, f1 is the modal class frequency, f0 comes before it, and f2 comes after it. The empirical relation Mode = 3 Median − 2 Mean is useful only for moderately skewed data.

Which formulas measure dispersion and variability?

Dispersion formulas measure how far observations spread around a central value. Variance is the average squared deviation from the mean. Standard deviation is its positive square root, in the same unit as the data.

MeasureUngrouped dataGrouped data
RangeMaximum − MinimumUpper limit of last class − Lower limit of first class

Variance (σ²)Σ(x − x̄)² / nΣf(x − x̄)² / N
Shortcut varianceΣx² / n − (x̄)²Σfx² / N − (Σfx / N)²
Standard deviationσ = √varianceσ = √variance
Coefficient of variation(σ / x̄) × 100(σ / x̄) × 100


Here, a can be the mean or the median, and N equals Σf. A lower coefficient of variation means more consistent data. Keep these JEE Main Statistics Formulas on a single revision page and test yourself on them every week.

How do shifting and scaling change these measures?

Adding a constant k to every observation shifts the mean by k and leaves the variance and standard deviation unchanged. Multiplying every observation by k scales the mean by k, the standard deviation by |k|, and the variance by k².

Change in dataMeanStandard deviationVariance
Add k to each valuex̄ + kσσ²
Multiply each value by kk x̄|k| σk² σ²


Two more results save time. For two groups, the combined mean is (n1 x̄1 + n2 x̄2) / (n1 + n2). The combined variance is [n1(σ1² + d1²) + n2(σ2² + d2²)] / (n1 + n2), where d1 = x̄1 − x̄ and d2 = x̄2 − x̄. For the first n natural numbers, the mean is (n + 1) / 2 and the variance is (n² − 1) / 12.

How should you practise statistics for JEE Main step by step?

Practise by learning the formulas first, solving basic numerical problems next, and then timing mixed questions. Focus on accuracy, because most statistics errors come from arithmetic slips and wrong formula selection.

  4. Practise the assumed mean and step deviation methods to reduce calculation time.

How do you apply these formulas in practice questions?

Applying the formulas means choosing the right form, filling in values carefully, and checking the answer for sense. These examples show the shortcut for deviations and the transformation rules.

Example 1. Find the variance and standard deviation of 2, 4, 4, 4, 5, 5, 7, 9.

The mean is 40 / 8 = 5. The squared deviations are 9, 1, 1, 1, 0, 0, 4, and 16, and they sum to 32. The variance is 32 / 8 = 4, so the standard deviation is 2.

Example 2. A data set has mean 5 and variance 4. Each value is multiplied by 3 and then increased by 2. Find the new mean and variance.

The new mean is 3 × 5 + 2 = 17. The variance is multiplied by 3², so it becomes 9 × 4 = 36. The added 2 does not change it.

Practice question. Find the variance of 3, 5, and 7. The mean is 5, and the squared deviations are 4, 0, and 4, so the variance is 8 / 3.

Which common mistakes lower marks in statistics questions?

The most common mistakes are forgetting the class width in step deviation, using the wrong median class, and treating variance as if it had the same unit as the data. Checking each step prevents most of them.

  1. Forgetting h in the step deviation method: multiply Σfu / Σf by the class width h before adding A.
  2. Using the wrong median class: find the first class where the cumulative frequency reaches or exceeds N / 2.
  3. Confusing variance and standard deviation: take the square root of variance as the last step.
  4. Changing variance after adding a constant: variance stays the same when the same number is added to every value.
  5. Using the wrong centre for mean deviation: it can be taken about the mean or the median, so read the question carefully.

Key Takeaways

  1. Learn the grouped data forms of mean, median, mode, and variance along with the ungrouped ones.
  2. Variance equals the mean of squares minus the square of the mean.
  3. Adding a constant changes the mean but not the spread.
  4. Multiplying by k multiplies variance by k² and standard deviation by |k|.
  5. Use the assumed mean and step deviation methods to save time with grouped data.
  6. Confirm the final syllabus on the official NTA website before the exam.

Frequently Asked Questions (FAQs)

FAQ 1: Which statistics formulas are most important for JEE Main?

Mean, median, mode, mean deviation, variance, standard deviation, and coefficient of variation are the core ones. Also learn the shortcut variance formula and the effect of shifting and scaling on the mean and spread.

FAQ 2: What is the shortcut formula for variance?

Variance equals Σx² / n − (x̄)² for ungrouped data. For grouped data, it is Σfx² / N − (Σfx / N)². It avoids finding every deviation separately and saves time.

FAQ 3: Does adding a constant to all observations change the variance?

No. Adding the same constant moves every value and the mean by the same amount, so the distances from the mean stay the same. The variance and standard deviation do not change.

FAQ 4: How can students practise numerical questions from this chapter?

Start with NCERT exercises, then move to previous year JEE Main questions. Solve grouped data problems with the step deviation method, check each answer, and note which formula caused errors.

FAQ 5: Is the empirical relation between mean, median, and mode always valid?

No. Mode = 3 Median − 2 Mean works only as an approximation for moderately skewed data. Use the direct modal class formula when the question gives a frequency table.

FAQ 6: How should students check the latest JEE Main statistics syllabus?

Download the official JEE Main Mathematics syllabus from the NTA website for the exam year. Compare the statistics topics with your notes and remove anything not listed there.
